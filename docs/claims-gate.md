# Claims Gate

## Evidence Tags

- `MEASURED`: produced by this repo's code, logs, tests, or directly measured experiment data.
- `PRIMARY_SOURCE`: supported by a cited paper, primary publication, code repository, or dataset card.
- `HYPOTHESIS`: proposed mechanism not yet experimentally established.
- `SPECULATION`: conceptual frame without a current test.
- `DENY`: claim should not be made from current evidence.

## Allowed Current Claims

- `PRIMARY_SOURCE`: large sodium nanoparticle matter-wave interference has been reported in Nature.
- `PRIMARY_SOURCE`: Brain2Qwerty reports constrained non-invasive MEG typed-sentence decoding with public code and a public v1 dataset.
- `HYPOTHESIS`: neural/prism streams may be useful high-dimensional controls for schedule selection.
- `MEASURED`: simulator outputs and policy comparisons produced by this repository after tests are run.

## Denied Current Claims

Do not claim from this repo alone:

- consciousness directly controls quantum collapse,
- organoids project mind into a matter-wave experiment,
- Q-PRISM proves quantum consciousness,
- Brain2Qwerty proves arbitrary thought reading,
- Brain2Qwerty proves neural control of a quantum system,
- a human subject's conscious stream has been physically projected into sodium nanoparticle superposition.

## First Strong Claim Target

The first serious claim this project can earn is:

> A blinded Q-PRISM control policy improved interferometer prediction/control metrics over random and classical baselines under pre-registered scoring.
